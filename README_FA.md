# 🛠️ Toolify

**Toolify** یک پلتفرم ماژولار و متن‌باز برای ساخت، مدیریت و اشتراک‌گذاری ابزارهای کاربردی وب است.

هدف پروژه این است که مجموعه‌ای از ابزارهای محاسباتی، توسعه‌دهنده، امنیتی و عمومی را در یک محیط سریع، مدرن و تا حد امکان مستقل از سرور در اختیار کاربران قرار دهد.

> ⚡ پردازش ابزارها به‌صورت Client-Side انجام می‌شود و معماری پروژه برای اضافه‌کردن ابزارهای جدید به شکل ماژولار طراحی شده است.

---

## ✨ ویژگی‌ها

- 🧩 **معماری کاملاً ماژولار**
- 🛠️ امکان اضافه‌کردن ابزارهای جدید بدون تغییر اساسی در هسته برنامه
- ⚡ **Lazy Loading** برای بارگذاری ابزارها در زمان نیاز
- 🌐 اجرای ابزارها در سمت کلاینت
- 🔒 طراحی با تمرکز بر حریم خصوصی و پردازش محلی
- 📱 رابط کاربری Responsive
- 🌙 رابط کاربری مدرن Dark
- 📦 قابلیت نصب به‌عنوان **PWA**
- 🚀 ساخته‌شده با Vite برای توسعه و Build سریع
- 🎨 رابط کاربری مبتنی بر Tailwind CSS
- 🧱 ساختار مناسب برای توسعه و گسترش بلندمدت
- 🧭 سیستم Registry برای مدیریت ابزارها
- 📊 قابلیت بررسی و پایش Performance
- 🔌 قابلیت توسعه ابزارها به‌صورت مستقل از یکدیگر

---

## 🧠 ایده اصلی

Toolify بر پایه یک ایده ساده ساخته شده است:

> **یک هاب واحد برای ابزارهای کوچک و کاربردی که بتوانند مستقل از Backend و در مرورگر کار کنند.**

به‌جای اینکه برای هر ابزار یک وب‌سایت یا پروژه جداگانه ساخته شود، Toolify یک هسته مشترک در اختیار ابزارها قرار می‌دهد.

هر ابزار می‌تواند به‌صورت یک ماژول مستقل تعریف شود و از طریق Registry در برنامه ثبت شود.

ساختار کلی معماری به شکل زیر است:

```text
                    ┌──────────────────────┐
                    │       Toolify        │
                    │      Web Hub         │
                    └──────────┬───────────┘
                               │
                       Tool Registry
                               │
          ┌────────────────────┼────────────────────┐
          │                    │                    │
          ▼                    ▼                    ▼
     Tool Module A        Tool Module B        Tool Module C
          │                    │                    │
          ▼                    ▼                    ▼
       Client              Client              Client
      Processing          Processing          Processing
```

هر ابزار می‌تواند منطق و UI مخصوص خودش را داشته باشد، در حالی که مدیریت کلی برنامه توسط هسته Toolify انجام می‌شود.

## 🏗️ معماری

ساختار پروژه به‌گونه‌ای طراحی شده که بخش‌های مختلف از یکدیگر جدا باشند:

```text
src/
├── components/
│   ├── ToolCatalog
│   ├── PwaInstallPrompt
│   └── Footer
│
├── core/
│   ├── registry/
│   ├── types/
│   ├── hooks/
│   └── pwa/
│
├── tools/
│   └── ...
│
└── App.tsx
```

### Tool Registry

Registry مسئول شناسایی، مدیریت و بارگذاری ابزارها است.

به‌جای اینکه تمام ابزارها هنگام اجرای برنامه وارد Bundle اصلی شوند، ابزار انتخاب‌شده در زمان نیاز Load می‌شود.

این معماری باعث می‌شود اضافه‌شدن ابزارهای بیشتر الزاماً به معنی بارگذاری همه آن‌ها در ابتدای اجرای برنامه نباشد.

### Lazy Loading

هنگامی که کاربر یک ابزار را انتخاب می‌کند:

```text
User
  │
  ▼
Select Tool
  │
  ▼
Tool Registry
  │
  ▼
Dynamic Import
  │
  ▼
Load Tool Module
  │
  ▼
Render Tool
```

## 🔐 Privacy

Toolify برای ابزارهایی که قابلیت اجرای Client-Side دارند، پردازش را مستقیماً داخل مرورگر انجام می‌دهد.

به این ترتیب می‌توان ابزارهایی ساخت که برای عملکرد خود به Backend اختصاصی نیاز ندارند.

این معماری برای ابزارهایی مانند:

- مبدل‌ها
- محاسبه‌گرها
- ابزارهای پردازش متن
- ابزارهای Developer
- ابزارهای رمزنگاری Client-Side
- Generatorها
- ابزارهای تحلیل داده‌های محلی

مناسب است.

> **نکته:** میزان حفظ حریم خصوصی هر ابزار به پیاده‌سازی همان ابزار بستگی دارد. ابزارهایی که در آینده به API یا سرویس خارجی نیاز داشته باشند ممکن است داده را به سرویس مربوطه ارسال کنند.

## 📱 PWA

Toolify دارای قابلیت‌های Progressive Web App است.

در نتیجه می‌توان پروژه را به‌گونه‌ای استفاده کرد که تجربه‌ای شبیه یک اپلیکیشن مستقل ارائه دهد.

Service Worker نیز در هنگام اجرای برنامه ثبت می‌شود.

## 🚀 شروع کار

### پیش‌نیازها

برای اجرای پروژه به موارد زیر نیاز دارید:

- Node.js
- npm

### Clone

```bash
git clone https://github.com/sepantartd/toolify.git
cd toolify
```

### نصب وابستگی‌ها

```bash
npm install
```

### اجرای محیط توسعه

```bash
npm run dev
```

پس از اجرای دستور، آدرس Local که توسط Vite نمایش داده می‌شود را در مرورگر باز کنید.

## ➕ اضافه‌کردن ابزار جدید

Toolify با هدف اضافه‌شدن آسان ابزارهای جدید طراحی شده است.

برای اضافه‌کردن یک ابزار جدید، معمولاً باید:

1. ماژول ابزار را ایجاد کنید.
2. Manifest ابزار را تعریف کنید.
3. Component مربوط به ابزار را پیاده‌سازی کنید.
4. ابزار را در Registry ثبت کنید.
5. Build پروژه را بررسی کنید.

یک ابزار باید تا حد امکان مستقل باشد و منطق داخلی خودش را درون ماژول خود نگه دارد.
